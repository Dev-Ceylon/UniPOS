# ADR-011: UI: Tailwind CSS variables and in-house primitives

- Status: Accepted
- Date: 2026-10-13

## Context

Theme colours must change per tenant at runtime and the UI must meet WCAG 2.2 AA.

## Decision

- Design tokens ("Classic Blue" palette, dark mode) are CSS variables in `packages/ui/src/tokens.css`, mapped into Tailwind v4 with `@theme inline`.
- `packages/ui` holds small accessible primitives (Button, Field, Dialog on native `<dialog>`, Table…) in the shadcn style without a generator dependency.
- The tenant's primary colour and radius are injected on `<html>`; the theme editor checks contrast.

## Consequences

Runtime theming with no rebuild; axe checks in Playwright on key screens.
